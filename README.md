# AI Generalist (Design) Portfolio

Open `index.html` in a browser. Keep the `assets` folder beside it when publishing.

All included project visuals are illustrative UI mockups, not real screenshots or proof of deployed functionality. The mobility study is an independent concept, not an Ather product. Verify contact details and make sure every project claim matches work you can defend in an interview.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `README.md`, and the entire `assets` folder to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Wait for the published URL and test it in a private browser window.
